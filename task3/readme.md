## Создание векторного индекса базы знаний

### 1. Выбор модели эмбеддингов

В соответствии с исследованием из Задания 1 и ограничениями по конфиденциальности данных, выбрана **локальная модель эмбеддингов**:

- **Модель**: `sentence-transformers/all-MiniLM-L6-v2`
- **Репозиторий**: [Hugging Face](https://huggingface.co/sentence-transformers/all-MiniLM-L6-v2)
- **Размерность вектора**: 384
- **Преимущества**: быстрая, лёгкая, работает полностью на CPU без необходимости GPU, поддерживает английский язык (основной язык базы знаний).

### 2. Подготовка чанков

Тексты из папки `knowledge_base/` разбиты на логические фрагменты с сохранением контекста.

- **Инструмент**: `RecursiveCharacterTextSplitter` из библиотеки `langchain`.
- **Размер чанка**: 500 символов.
- **Перекрытие**: 100 символов для плавности переходов.
- **Метаданные**: для каждого чанка сохраняется путь к исходному файлу и заголовок (из первой строки документа).

### 3. Генерация эмбеддингов и создание индекса

Скрипт `build_index.py` выполняет полный цикл:
1. Чтение всех `.md` файлов из `knowledge_base/`.
2. Разбиение на чанки с метаданными.
3. Векторизация с помощью `HuggingFaceEmbeddings`.
4. Сохранение индекса Chroma (папка `chroma_index/`).

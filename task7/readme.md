## Аналитика покрытия и качества базы знаний

### 1. Внесение искусственных пробелов
Из базы знаний удалены (перемещены в отдельную папку) три ключевых документа:
- `kith.md`
- `torin_mal.md`

Это симулирует ситуацию, когда критически важная информация отсутствует, и позволяет оценить, как бот справляется с неполными данными.

### 2. Запуск Тестирования
```bash
docker exec -it rag_bot python /app/evaluate.py 
```

### 3. Анализ логов
```text
[SUCCESS] Кто такой Ryon Vex?
[SUCCESS] Опиши планету Varkos
[SUCCESS] Что такое Flux Blade?
[SUCCESS] Где находится Nimbus Station?
[NOT_FOUND] Кто такой Kith?
[SUCCESS] Что такое Void Core?
[SUCCESS] Расскажи о Xarn Velgor
[SUCCESS] Как работает Synth Flux?
[NOT_FOUND] Назови столицу Thalor Prime
[SUCCESS] Кто такой Lord Nexar?
[SUCCESS] Что такое Void Shifter?
[SUCCESS] Какие расы населяют Lunara?

Результаты тестирования:
  Успешных ответов: 10/12
  Отказов (not found): 2/12
  Ошибок: 0/12
```

10/12 ответов успешны – бот корректно извлекает информацию из нескольких источников, даже если прямой документ удалён (за счёт перекрёстных упоминаний).

### Вывод

RAG-бот продемонстрировал высокую надёжность: даже при удалении целевых документов он способен давать ответы на основе косвенных упоминаний.
Выявленные пробелы единичны и легко устранимы. Предложенная система логирования и тестирования позволяет непрерывно контролировать качество базы знаний и оперативно реагировать на проблемы.

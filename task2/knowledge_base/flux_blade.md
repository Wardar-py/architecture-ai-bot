# Flux Blade

Flux Blade – ритуальное оружие Aether Knights и Void Wardens. Клинок из чистой энергии, заключённый в рукоять, способен разрезать практически любой материал. Цвет Flux Blade отражает связь владельца с Synth Flux: зелёный и синий — у защитников, красный — у тёмных последователей. Создание собственного клинка является важным испытанием для каждого Aether Knight'а.

# Aether Knights

Aether Knights – древний орден защитников мира в галактике. Они черпали силу из Synth Flux, используя её для сохранения равновесия. Их оружием был Flux Blade – клинок из чистой энергии. Во времена расцвета Nexar Dominion орден был почти полностью истреблён Void Warden'ами. Немногие выжившие, такие как Torin Mal и Kith, скрывались на отдалённых планетах.

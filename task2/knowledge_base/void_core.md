# Void Core

Void Core – боевая станция Nexar Dominion размером с небольшую луну. Оснащена суперлазером, способным уничтожать целые планеты. Первая Void Core была разрушена Ryon Vex'ом во время битвы при Lunara. Вторая, более мощная версия, строилась на орбите Iskara, но также была уничтожена силами Free Worlds Coalition.

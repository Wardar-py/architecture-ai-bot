## Автоматическое ежедневное обновление базы знаний

### 1. Выбор источника данных
В качестве источника используется **локальная папка `task2/knowledge_base/`**.
Изменения отслеживаются по дате модификации файлов.

### 2. Скрипт обновления индекса `update_index.py`

Скрипт сравнивает файлы в папке с сохранённым состоянием (`index_state.json`),
выделяет новые и изменённые, разбивает их на чанки, векторизует и добавляет в ChromaDB. Также ведётся лог.
